# components/apply/ — 교사 신청 화면 컴포넌트

`/apply`(공개)에서만 쓰는 컴포넌트. 화면 오케스트레이션은 `app/apply/page.tsx`에 있다.

| 파일 | 역할 |
|---|---|
| `RosterEditor.tsx` | 명단 파일 업로드(.xlsx/.csv) → 고정 4칸 표(번호·이름·성별·생년월일) → 칸 수정. 파싱은 `lib/xlsx`+`lib/roster`, 확정 명단만 `onChange`로 올린다 |

## 파일은 브라우저에서만 읽는다

명렬표에는 주민등록번호가 들어 있을 수 있다. 파일을 서버로 올리지 않고 여기서 파싱해
**네 칸만** 서버로 보내면 그 값은 애초에 서버에 도달하지 않는다(`lib/xlsx.ts` 주석).

## 열 역할 지정 UI를 만들지 말 것

`lib/roster`가 알려진 머리글 이름으로만 열을 찾고, 못 찾으면 양식을 안내한다. 값 모양으로
추론하면 "반 번호 2"를 성별로 오인한다(프로토타입에서 확인).

## 명단 유효성은 이 폴더가 소유한다

`onChange(roster | null)` 한 줄이 부모와의 계약 전부다 — 한 칸이라도 틀리거나 표가 비면
`null`이고, 부모는 그것으로 제출 버튼을 잠근다. 통보는 **표를 바꾸는 함수(`commit`)에서**
하고 `useEffect`로 하지 않는다(부모가 매 렌더 새 `onChange`를 넘길 때의 루프 회피).

생년월일 칸은 값이 `normBirth`로 읽힐 때만 `type="date"`다. `type="date"`는 형식이 어긋난
값을 표시하지 못해, 파일에서 온 잘못된 값을 조용히 지워 버린다.
