# components/start/ — 시작 화면의 교사용 블록(쓰기 기록지 인쇄 · 메일 링크)

시작 화면(`app/page.tsx`)은 코드를 확인하면 블록으로 나뉜다(담당자 요청 2026-10-22) — 학급 코드 · 현재 검사 상황 · 검사할
학생 · 쓰기 기록지 · 쓰기 스캔본 · 결과지. 이 폴더는 아래 셋(교사용)의 부품이다.

「쓰기 기록지」 블록의 [쓰기 기록지 인쇄]가 여는 창과 인쇄되는 종이. 쓰기를
「스캔본으로 올리기」로 하는 반이 아이들에게 나눠 줄 기록지를 뽑는다(담당자 확정 2026-09-30 — 과정만, 회신은 사용자 전달,
흐름은 사용자 확정 2026-09-30 — 담당자에게 시안 공유).

| 파일 | 역할 |
|---|---|
| `WritingSheetDialog.tsx` | 인쇄 확인 창(바깥을 눌러도 닫히지 않는다 — 골라 둔 것이 사라진다) — 처음에는 요약과 [인쇄하기 (N장)]만(가장 흔한 「검사 전 반 전체」는 한 번이면 끝난다). 「학생 골라서 뽑기」를 펼치면 명단에서 고른다(쓰기 상태 배지: 화면 입력함 · 스캔 올림 · 스캔 대기). 명단에 없는 학생은 **번호만 찍힌 기록지**(명단 번호를 넣으면 그 학생을 고른 것으로 돌린다 — 이름이 찍혀 나오는 편이 낫다), 명단 없는 학급은 M번~N번(시작 번호 기본 1 — 3~17번만 다시 뽑을 수 있게 고칠 수 있다, 2026-10-13. 앞이 뒤보다 크면 「앞 번호가 뒤 번호보다 커요.」) + 낱장 번호(한 장만 다시 뽑을 때). [인쇄하기]는 **브라우저 인쇄 창을 바로** 연다 — 파일로 저장하지 않는다(아이 앞 공용 PC의 다운로드 폴더에 반 전체 이름이 남지 않게) |
| `LinkByMail.tsx` | 「쓰기 스캔본」·「결과지」 블록의 [쓰기 스캔본 올리기]·[결과지 받기] — 등록된 담임 메일로 학급 결과 화면 링크를 보낸다(`POST /api/results/request`, `purpose`). 이 화면에서는 아무것도 열리지 않는다 — 아이 앞 공용 기기라서다(결과지 사용자 확정 2026-09-22, 스캔본은 사용자·담당자 확정 2026-10-22 — 코드만으로 올리게 하면 아이 앞 기기에서 아동 기록에 그림을 올릴 수 있다). 보낸 뒤 「k***@…로 ○○ 링크를 보냈어요」와 60초 카운트다운(종류마다 따로 — 서버가 코드·종류로 센다). 학급이 바뀌면 문구가 남지 않게 호출부가 `key`로 학급 코드를 준다 |
| `WritingSheets.tsx` | 인쇄되는 기록지 한 장(A4) — 제목 · QR · 학교/학년·반/번호/이름(명단에서 자동) · 쓰는 칸 · 바닥글(스캔 안내·보관 안내) |

## 지키는 것

- **기록지는 지금 판이 정식 양식이다** — 담당자 확정(인계 확인 사항 PDF 2026-10-12판 회신 2번, 2026-10-22 사용자 전달) — 원문 「제목만 수정하면 그대로 가도 될 것 같아(현: 쓰기 기록지, 변경: 받아쓰기)」 「2학년은 1~5번 문항만 남기고 가로 폭만 더 길어지면」. 그래서 머리 작은 글씨가 「받아쓰기」다. 종전에는 담당자가 양식을 따로 주기로 해 임시본이었다.
  양식을 다시 바꾸더라도 아래는 바뀌지 않는다.
- 검사 화면의 첫 안내는 「종이의 이름이 N번 ○○인지 확인하고 건네 주세요」다(`components/survey/WritingMode.tsx`).
- **QR에는 반 표시와 번호만**(`SHEET-W:<반 표시 8자리>:<번호 2자리>`, `lib/writing-sheet` — 검사 이름도 싣지 않는다). 학급 코드는
  그 반 명단의 비밀번호라 종이에 뿌리지 않고, 주소를 넣으면 휴대폰으로 찍은 사람이 사이트로 들어온다.
  QR은 직접 만든다(`lib/qr` — 외부 라이브러리 없이 ISO 18004, 세그노 벡터와 대조한 테스트가 있다).
- **목표 낱말·문장은 인쇄하지 않는다**(받아쓰기). 이 화면은 문항을 받지도 않는다 — 서버는 쓰는 칸의
  종류와 개수만 준다(`verify-code`의 `sheet.layout`).
- 제목에 「난독」「검사」처럼 평가를 드러내는 말을 쓰지 않는다 — 아이가 손에 쥐는 종이다.
- **창을 열 때만 그린다**(`{open && <WritingSheetDialog …/>}`) — 고른 학생이 열 때마다 반 전체에서 시작한다.
  열린 채 상태를 되돌리는 효과로 두면, 시작 화면이 1초마다 다시 그려질 때(결과지 받기 카운트다운 — 지금은 `LinkByMail` 안에서만 다시 그려진다) 고른 것이 풀렸다.

## 인쇄 방식

기록지를 `#sheet-print-root`(body 직속 포털, 화면에는 안 보인다)에 그리고, **이름 글자의 한글 글꼴 조각을 받은
뒤**(`document.fonts.load` — 숨긴 글자는 미리 받아지지 않아 안 기다리면 다른 글꼴로 찍힐 수 있다) `window.print()`.
인쇄하는 동안 `body.printing-sheets`가 다른 요소를 인쇄에서 숨기고(`app/globals.css`의 `@media print`), 문서 제목을
「쓰기 기록지」로 잠시 바꾼다. 인쇄 창이 닫히면(`afterprint`) **인쇄 상태만 풀고 창은 남긴다** — 크롬은 인쇄를 취소해도
`afterprint`가 와서, 창을 닫아 버리면 프린터를 잘못 골라 취소한 선생님이 고른 학생을 다시 골라야 한다(2026-10-01).
인쇄 뒤에는 [취소]가 [닫기]로 바뀌고 「더 뽑을 게 없으면 닫기」 안내가 뜬다. `afterprint`가 오지 않는 브라우저여도 같다.

**기록지를 인쇄하는 동안은 쪽 여백이 0이다** — 브라우저(크롬·엣지·웨일)가 기본으로 여백에 찍는
머리글·바닥글(페이지 제목·사이트 주소·날짜)이 아이 종이에 나오지 않게 한다(QR에서 주소를 뺀 것과 같은 이유).
그 `@page { margin: 0 }`은 인쇄 창이 `<style>`로 **넣었다 뺀다**(전역 결과지용 @page보다 뒤라 이긴다). 이름 붙은
쪽(`@page sheet`)으로 하지 않는 이유는 그것을 모르는 브라우저(Safari 등)가 기본 여백에 기록지를 올려 한 장이 두 쪽으로
넘치기 때문이다(2026-10-01 바꿈). 여백 12mm·10mm는 기록지 안쪽 padding이 대신하고, 한 장은 A4보다 조금 작은
210×296mm다(딱 맞추면 반올림으로 빈 쪽이 생긴다).
