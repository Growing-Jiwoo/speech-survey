# components/survey/ — 참여자(아동) 검사 화면 컴포넌트

만 6-7세 아동이 교사 보조 하에 사용하는 화면. **큰 터치 타깃, 즉각적 피드백, 오터치 방지,
평가 신호(칭찬/실망) 비노출**이 설계 원칙이다. `app/survey/page.tsx`가 **페이지 종류**에 따라
아래 컴포넌트를 골라 렌더한다(화면·녹음의 단위는 문항이 아니라 페이지다 — `lib/items.ts`의 `itemsFor(양식).pages`).
페이지 목록은 **세션의 학년**이 정한 검사지에서 나온다 — 쓰기 과제 화면이 학년마다 다르다.

| 파일 | 페이지/역할 |
|---|---|
| `MicCheck.tsx` | 검사 시작 전 마이크 확인 — "안녕하세요" 발화의 peak로 판정, 실패 종류별(거부/미지원/실패) 안내. 성공 후 재확인 가능 |
| `PracticeAsk.tsx` | 연습 실시 여부 선택(마이크 확인 다음) — 같은 아동의 반복 검사에서 매번 연습을 강요하지 않기 위해 검사자가 고른다 |
| `PracticeEnd.tsx` | 연습 종료 안내 — 연습과 본 검사의 경계를 화면으로 분명히 한다(연습 페이지에서 [다음]을 누른 직후 한 번) |
| `SectionIntro.tsx` | 섹션 진입 안내 — 주제가 바뀔 때 "무엇을 하는지"를 아이 눈높이로 한 번 보여준다 |
| `ReadingPage.tsx` | 녹음 페이지(낱말 30초/문장 40초) — 한 화면의 낱말/문장 전체를 읽는다. 버튼을 누르면 곧바로 녹음이 시작된다(3·2·1 카운트다운은 2026-08-12 제거 — 연습 단계가 그 역할을 한다). 저장은 하지 않고 `onRecorded`로 상위에 넘긴다 |
| `MarkPage.tsx` | 의미 낱말 현장 채점 — 검사자가 O/X를 표시한다. 중단 규칙 판정의 입력 |
| `WritingPage.tsx` | 낱말 쓰기(G1) — 검사자가 문항별 예/아니오 선택. 중단 규칙 ②(**1번 낱말** 오반응)에 걸리면 남은 문항을 잠근다 |
| `SentenceWritingPage.tsx` | 문장 쓰기(G2) — 검사자가 **정확히 쓴 어절 수**(0·1·2)를 고른다. 중단 규칙 ②(첫 문장 0점)에 걸리면 남은 문항을 잠근다 |
| `ChecklistItem.tsx` | 검사자 체크리스트 — 발달 영역 다중 선택('특이사항 없음'과 상호 배타) |
| `RetryBanner.tsx` | 업로드 실패 녹음 재시도 배너 — 페이지를 이동해도 유지, 연타 중복 업로드 가드 |

녹음 자체(MediaRecorder·레벨미터·타이머)는 `hooks/useRecorder.ts`가 담당한다.

## 녹음 저장은 낙관적이다 (2026-08-12)

`ReadingPage`는 업로드하지 않는다 — 녹음이 끝나면 `onRecorded(rec)`로 상위(`app/survey/page.tsx`)에
넘기고, 상위가 **완료로 먼저 표시한 뒤 백그라운드로 업로드**한다. 실패하면 그 표시를 되돌리고
`RetryBanner`를 낸다. 업로드를 기다리는 동안 화면을 잠갔더니 [다음] 버튼이 "모르겠어요"로 보이고
몇 초씩 멈춰 검사 흐름이 끊겼다(사용자 보고) — 그래서 이 화면에는 "저장 중" 대기 UI가 없다.
진행 중인 업로드는 헤더의 `저장 중…` 표시와 새로고침 경고(beforeunload)로만 드러난다.
