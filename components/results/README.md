# components/results/ — 교사 결과지 화면

`/results/[token]`(학급 스코프 토큰)에서 교사가 본인 학급 결과지를 받는 화면. 스펙:
`docs/superpowers/specs/2026-09-22-teacher-results-download-design.md`.

| 파일 | 역할 |
|---|---|
| `ResultsView.tsx` | `GET /api/results/<token>`을 읽어 요약 한 줄·아이별 행(재검사 펼침·체크박스)·[전체 PDF]/[선택 PDF]를 그린다. 401은 만료 화면(→ `/`), 그 외는 재시도. 다운로드는 `fetch → blob → a[download]`로 받아 로딩 표시를 낸다(앵커 직행은 무반응으로 보여 여러 번 누른다) 두 다운로드 버튼은 **확인 모달만 연다** — 받을 아이 명단(재검사가 있으면 차수까지)을 보여 주고 거기서 한 번 더 눌러야 요청이 나간다. 25장 병합은 서버가 몇 초를 쓰는 일이라 잘못 눌린 클릭 하나로 시작되면 안 된다(사용자 확정 2026-09-22, 담당자 회신 아님). 만드는 동안은 버튼 글자를 바꾸는 대신 **화면 전체를 덮는 공용 로딩 오버레이**를 쓴다 — 글자만 바뀌면 눌린 줄 모르고 다시 누른다 |

- 표의 계산(상태·판정·정렬·요약)은 전부 `lib/results.ts`가 한다 — 이 파일은 그린다.
- 판정은 관리자 화면과 같은 **Pass/Fail**(사용자 확정 2026-09-22). 채점 완료(`scored`)만 체크 가능.
- **기본 선택은 비어 있다.** 자동으로 채워 두면 고른 적 없는 교사가 「선택한 2장」을 보고 자기가 고른 줄 안다
  (사용자 지적 2026-09-22). 반 전체를 받는 길은 [전체 PDF 다운로드]가 따로 맡는다.
- 재검사 차수는 **배지**로 그린다(표·확인 모달 모두) — 어느 검사인지 가르는 값이라 회색 글자로는 안 띈다.
- 아이 행의 체크박스는 **그 아이의 채점 완료 차수 전부**를 맡는다(일부만 고르면 `indeterminate` 막대).
  종전에는 「최신 차수 하나」의 체크박스여서, 펼치면 같은 검사에 체크박스가 둘이 되고 2차만 골랐을 때
  이름 행이 꺼진 채라 상위처럼 보이는 칸이 거짓말을 했다(사용자 지적 2026-09-22).
- **받을 수 없는 행에는 체크박스를 그리지 않는다** — 아이 행이든 차수 행이든 같다. 잠긴 회색 상자는
  눌러도 반응이 없어 고장처럼 보이고, 「상자가 있으면 받을 수 있다」는 규칙 하나로 읽히게 하려는 것이다
  (사용자 확정 2026-09-23). 왜 못 받는지는 같은 줄의 상태 배지가 말한다.
- 녹음·요약표 CSV·행별 PDF는 **의도적으로 없다**(스펙 「화면에 없는 것」).

## 「채점 전」 — 되돌리기 가장 쉬운 결정

`complete[k] === false`인 과제는 점수 대신 **`채점 전`(mute 배지)**으로 그린다. 편의로 되돌리지 말 것:

- 쓰기는 검사 중 검사자가 넣는 값이라 관리자가 나중에 채울 수 없다. 그래서 쓰기가 비어도
  `scored`로 보고 결과지를 내보내는데(A안), 그 대가로 `scores.writing`에 **0이 들어온다.**
  그 0은 「0점을 받았다」가 아니라 **「아직 채점 전」**이다 — `0/10`으로 찍으면 치르지도 않은
  과제에서 낙제한 아동으로 읽힌다. 임상적 오독이다.
- 같은 이유로 `verdict`는 세 과제가 모두 채점돼야 값을 갖는다(아니면 판정 칸이 `-`). 흔하다.
- 근거: **사용자 확정(2026-09-22) A안 「관리자와 동일」 — 담당자 회신이 아니라 개발 판단이다.**
  관리자 결과지(`components/admin/ResultSheet.tsx`)가 이미 그렇게 하고, 두 화면이 같은 아이를
  다르게 말하면 그 자체가 사고다.
- 그래서 표 아래 **범례**(`components/admin/BadgeLegend.tsx` — 폴더만 admin일 뿐 범용)를 상시 둔다.
  항목은 `채점 전` · `Pass`/`Fail` · (`provisional`일 때만) `임시 기준 · 확정 전` 셋이고,
  문구는 관리자 화면과 같은 말을 하되 관리자 전용 조작(채점 저장·미녹음 기본 채점)은 뺀다.
