# scripts/ — 개발·운영 보조 스크립트 (tsx 실행)

| 스크립트 | 실행 | 역할 |
|---|---|---|
| `hash-password.ts` | `npm run hash-password -- '비밀번호'` | 관리자 비밀번호의 argon2id 해시 생성. **출력 2줄의 용도가 다르다**: "원본 해시"는 Vercel 대시보드용, "`.env.local`용"은 `$`를 `\$`로 이스케이프한 로컬 dotenv용(섞어 쓰면 로그인 불가 — 루트 README 셋업 절 참고) |
| `build-schools.ts` | `npm run build:schools [-- <원본디렉터리>]` | 전국 초등학교 원본 JSON을 지역별 경량 JSON(`public/schools/`)으로 변환. 생성물이 저장소에 커밋돼 있으므로 학교 데이터 갱신 때만 재실행 |
| `build-roster-template.ts` | `npm run build:roster-template` | 교사가 `/apply`에서 내려받는 **학급 명단 양식**(`public/roster-template.xlsx`) 생성. 머리글을 `lib/roster`의 `COL_LABEL`에서 가져오므로 그 상수를 고치면 **반드시 다시 돌릴 것** — 어긋남은 `tests/roster.test.ts`가 이 산출물을 실제 파서에 물려 잡는다. 데이터를 덤프한 격자가 아니라 **교사가 손으로 채우는 서식**이라 병합·색·테두리·머리글 고정·성별 드롭다운을 넣는다(빈 서식이 문의를 부른 전례 2026-08-21). ZIP·XML을 손으로 조립하지만 런타임이 아니라 여기 있는 이유는 파일 머리주석 참고 |
| `check-client-bundle.ts` | `npm run build`의 마지막 단계(단독: `npx tsx scripts/check-client-bundle.ts`) | `.next/static`(인증 없이 누구나 받는 JS 청크)에 **검사지 문항**이 실렸는지 검사하고, 있으면 빌드를 실패시킨다. 화면 코드가 `lib/forms`(또는 그것을 값으로 import하는 `lib/results`·`lib/session-progress`)를 import하는 순간 조용히 새는 종류라 리뷰로 잡기 어렵다. 찾는 것은 문장 읽기 문항과 따옴표로 감싼 무의미 낱말이다(두 글자 의미 낱말은 UI 문구와 우연히 겹칠 수 있어 뺐다). 실패하면 출력된 청크에서 어느 모듈이 끌고 왔는지 찾아 그 import를 서버 응답으로 바꿀 것 |
| `copy-pdfjs-wasm.mjs` | `npm run dev`·`npm run build`의 첫 단계(단독: `node scripts/copy-pdfjs-wasm.mjs`) | pdfjs의 wasm 해독기(JBIG2·JPEG 2000·색 관리)와 라이선스를 `node_modules/pdfjs-dist/wasm/`에서 `public/pdfjs-wasm/`로 복사한다. 스캔본 올리기(`lib/scan-pages.ts`)가 **흑백 스캔 PDF**를 그리려면 필요하다 — 없으면 그림이 빠져 모든 쪽이 빈 쪽이 된다. 생성물이라 `.gitignore`에 있고, pdfjs를 올리면 다음 dev·build가 새 파일로 다시 복사한다 |
| `vendor-fonts.mjs` | `node scripts/vendor-fonts.mjs` | 웹폰트를 구글에서 받아 `public/fonts/**`·`app/fonts.css`로 벤더링. **빌드가 네트워크를 타지 않게 하려는 것**이라 `next/font/google`로 되돌리면 안 된다(빌드마다 폰트를 받아 한 번의 실패로 배포가 죽는다). 생성물이 커밋돼 있으므로 폰트·웨이트를 바꿀 때만 재실행 — 스크립트의 `FAMILIES` 수정 후 실행. 폰트마다 **`OFL.txt`도 함께 받아 둔다** — OFL은 폰트 파일을 배포할 때 라이선스 문서를 같이 두는 것이 조건이고, 이 사이트는 woff2를 방문자에게 직접 내려보내므로 배포에 해당한다. 폰트를 추가하면 `FAMILIES`에 `ofl`(google/fonts 저장소의 디렉터리 이름)도 적을 것 |
