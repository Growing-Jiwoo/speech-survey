준비물

크롬이나 엣지 브라우저, 그리고 관리자 비밀번호 하나면 됩니다. 설치할 것은 없습니다.

1로그인과 화면 구성

  1. https://speech-survey.vercel.app/admin으로 들어갑니다 즐겨찾기에 넣어 두면 편합니다.
  2. 비밀번호를 넣고 로그인 아이디는 없습니다.
  3. 자리를 뜰 때는 로그아웃 검사 목록 오른쪽 위에 있습니다. 로그인은 8시간 뒤 저절로 끝납니다.
  • 채점 중에 로그인이 끝나면 화면 위에 다시 로그인이 뜹니다. 다시 로그인하면 보던 화면으로 돌아옵니다.
  • 비밀번호를 5번 틀리면 10분 동안 잠깁니다.

화면은 셋입니다

화면하는 일
검사 목록누가 검사했는지 보고, 채점할 아이를 고릅니다(3장 참고).
결과지목록에서 행을 누르면 열립니다. 녹음을 듣고 채점합니다(4장 참고).
학급 코드신청을 승인하거나 코드를 만듭니다. 검사 목록 오른쪽 위 학급 코드 발급으로 들어갑니다(2장 참고).

2학급 코드 승인·발급

학급 코드는 6자리입니다. 선생님은 이 코드를 넣어야 검사를 시작할 수 있습니다. 보통은 선생님 신청을 승인하고, 급할 때만 직접 발급합니다.

선생님 신청 승인하기

선생님은 https://speech-survey.vercel.app/apply에서 학급과 학생 명단을 올려 신청합니다. 신청이 들어오면 학급 코드 화면에 대기 중 N건이 뜹니다.

  1. 명단 보기로 명단을 확인합니다 실제 학급인지 봅니다. 확인이 끝나면 명단 닫기로 접어 두세요.
  2. 승인을 누릅니다 1~2초 걸립니다. 두 번 누르지 마세요.
  3. 뜨는 문구를 확인합니다 아래 표대로 하면 됩니다.
문구할 일
승인 완료 · 선생님께 코드 메일을 보냈어요끝입니다.
승인은 됐지만 메일을 보내지 못했어요안내 문구 복사를 눌러 선생님께 문자·메일로 직접 보내 주세요.
이미 승인된 학급이에요선생님이 코드를 받았는지 확인하고, 못 받았으면 안내 문구 복사로 보내 주세요.
신청을 거절하려면 삭제합니다

삭제하면 함께 올라온 명단도 지워지고 되돌릴 수 없습니다. 선생님께 알림이 가지 않으니 필요하면 따로 연락해 주세요.

코드를 직접 발급하기

신청 없이 학급을 열어야 할 때 씁니다.

  1. 학교·학년·반·담임 이름·이메일을 넣습니다 학교는 지역을 먼저 고르면 검색됩니다. 이메일은 꼭 넣어야 합니다. 결과지 링크가 이 주소로 갑니다.
  2. 코드 발급을 누릅니다 같은 반 코드가 이미 있으면 알림이 뜹니다. 대개는 있는 코드를 쓰면 됩니다.
  3. 코드 복사로 선생님께 전달합니다 메일이 자동으로 가지 않습니다. 검사 주소 https://speech-survey.vercel.app와 선생님용 설명서도 함께 보내 주세요.
직접 발급할 때 주의할 점

학교·학년·반은 나중에 고칠 수 없습니다(이메일만 고칠 수 있습니다). 명단이 없어서 선생님이 아이 정보를 직접 입력하게 됩니다.

수정담임 이메일을 고칩니다. 결과지 링크가 이 주소로 갑니다.
삭제검사 수가 0인 코드에만 나타납니다.

3검사 목록 보기

누가 검사했고 무엇을 채점할지 봅니다. 행을 누르면 결과지가 열립니다.

1숫자 카드. 누르면 그 조건으로 목록이 걸러지고, 다시 누르면 풀립니다.
2학교별 현황. 학교 이름을 누르면 그 학교만 봅니다.
3검색. 이름·학교·담임·반·번호로 찾습니다.
4진행률. 위가 녹음, 아래가 쓰기입니다. 쓰기를 스캔본으로 한 검사는 스캔 대기나 스캔본 채점이 보입니다.
5회차. 같은 아이를 다시 검사하면 1/2회차처럼 붙습니다.
6정렬. 열 제목을 누릅니다.

상태 표시

표시할 일
진행 중아직 제출하지 않은 검사입니다. 채점하지 마세요.
제출 완료채점하면 됩니다.
제출 · 미완료 있음미녹음 과제가 있는 검사입니다. 채점하면 됩니다. 빠진 녹음은 자동으로 0점이 됩니다.

스캔본으로 채점할 검사가 있으면 검색창 옆에 스캔본 채점 N 탭이 생깁니다.

4채점하기

결과지에서 녹음을 들으며 점수를 넣습니다. 손을 멈추면 저절로 저장됩니다.

1아이 정보. 틀렸으면 정보 수정으로 고칩니다.
2검사지. G1은 1학년, G2는 2학년입니다.
3총평. 과제별 점수와 Pass/Fail입니다.

채점 순서

  1. 목록에서 제출된 검사를 엽니다 진행 중인 검사는 채점하지 않습니다.
  2. 낱말 해독: 녹음을 들으며 낱말마다 O 또는 X를 누릅니다 20초 안에 맞게 읽은 낱말이 O입니다.
  3. 문장 읽기: 문장마다 읽은 시간(초)과 맞게 읽은 어절 수를 넣습니다 시간은 녹음을 들으며 아이가 실제로 읽은 시간을 넣습니다. 녹음 길이를 그대로 쓰지 않습니다. 녹음이 없는 문장은 20초·0어절로 자동으로 채워집니다. 네 문장을 다 넣으면 총점(1초에 읽은 어절 수)이 계산됩니다.
  4. 쓰기: 화면에서 표시한 검사는 이미 채워져 있습니다 스캔본으로 한 검사는 아래 「스캔본으로 쓰기 채점」대로 합니다.
  5. 「자동 저장됨」을 확인합니다 오류가 뜨면 채점 저장을 눌러 주세요.
  6. 결과보고서 PDF 다운로드 또는 다음 아동 ▶ 다음 아동은 목록에서 보던 순서대로 넘어갑니다.
녹음 듣기 요령

재생기를 누른 뒤 스페이스로 재생·정지, ← →로 5초씩 옮깁니다. 배속을 0.75배로 낮추면 받아 적기 쉽습니다. 다시 녹음한 과제는 1차 2차 칩으로 골라 들을 수 있습니다. 재생이 안 되면 다시 받기를 누르세요.

스캔본으로 쓰기 채점

  1. 왼쪽 스캔본을 보고 오른쪽 칸을 채웁니다 1학년은 O/X, 2학년은 맞게 쓴 어절 수(0·1·2)입니다. 확대·회전할 수 있습니다.
  2. 다른 아이의 기록지면 이 아이 기록지가 아니에요 — 연결 해제 선생님께 맞는 기록지를 다시 올려 달라고 연락해 주세요.

미녹음녹음이 없습니다. 자동으로 0점이 되고 고칠 수 없습니다.
저장 실패아이가 읽었지만 녹음이 올라오지 않았습니다. 0점으로 처리됩니다.

아이 정보 고치기와 기록 삭제

결과지 위쪽 정보 수정에서 번호·이름·성별·생년월일을 고칩니다. 학년과 반은 고칠 수 없습니다.

검사 기록 삭제는 되돌릴 수 없습니다

결과지 맨 아래 검사 기록 삭제를 누르면 녹음·점수·아이 정보가 모두 지워집니다. 지우기 전에 결과보고서 PDF를 먼저 받아 두세요.

5결과보고서 PDF

채점을 마친 뒤 학교와 보호자에게 가는 결과 문서입니다. 결과지 아래 결과보고서 PDF 다운로드로 받습니다.

  • 과제별 PASS/FAIL, 최종결과, 해석 문구, 체크리스트가 들어갑니다.
  • 채점을 저장하지 않았거나 낱말·문장 채점이 남아 있으면 받을 수 없다고 알려 줍니다.
  • 쓰기만 비어 있으면 받을 수 있고, 그 칸은 비어서 나옵니다.
선생님은 직접 받아 갑니다

선생님이 검사 화면의 결과지 받기 →로 메일 링크를 받아 내려받습니다. 관리자는 채점만 끝내면 됩니다.

6이럴 때는

선생님이 코드를 못 받았대요

학급 코드 화면에서 그 학급을 찾습니다. 대기 중이면 승인을, 발급 목록에 있으면 그 코드와 검사 주소 https://speech-survey.vercel.app를 알려 주세요.

선생님이 「코드를 확인해 주세요」가 뜬대요

아직 승인하지 않았거나, 코드를 지웠거나, 잘못 친 것입니다. 코드에는 0·O·1·I·L이 쓰이지 않습니다.

결과지 링크 메일이 다른 주소로 갔대요

학급 코드 발급 목록에서 그 학급의 수정으로 이메일을 고친 뒤, 선생님께 다시 받으라고 알려 주세요.

녹음이 안 들리거나 비어 있어요

선생님께 연락해 다시 검사해 달라고 요청하세요. 다시 검사하면 새 회차로 쌓이고 이전 기록은 남습니다.

선생님이 쓰기를 잘못 넣고 제출했대요

화면에서 표시한 쓰기는 고칠 수 없습니다. 선생님께 다시 검사해 달라고 하고, 새 기록이 들어오면 이전 기록을 지우세요.

같은 아이가 목록에 두 번 있어요

다시 검사한 것입니다. 선생님께 확인한 뒤 필요 없는 쪽을 지우세요.

학급 코드를 지우려는데 삭제 버튼이 없어요

그 코드로 한 검사 기록이 있어서입니다. 검사 기록을 먼저 지워야 합니다.

채점이 저장됐는지 모르겠어요

「자동 저장됨」이 보이면 저장된 것입니다. 오류가 보이면 창을 닫지 말고 채점 저장을 누르세요.

비밀번호를 잊었어요

화면에서 다시 만들 수 없습니다. 개발 담당자에게 새 비밀번호를 요청하세요.

지켜 주세요

자리를 뜰 때는 로그아웃합니다. 명단은 확인한 뒤 바로 접습니다. 오래 방치된 신청은 정리합니다(아이 명단이 붙어 있습니다).
