3마이크 확인

이 단계를 통과해야 검사를 시작할 수 있습니다. 처음 한 번은 브라우저가 마이크 사용을 물으니 허용을 누르세요.

시작 전에 아이에게 알려 주세요

① 힘들면 언제든 멈출 수 있어요. ② 읽기 어려우면 모르겠어요를 눌러 넘어가도 돼요. ③ 녹음은 검사를 확인하는 선생님만 들어요.

  1. 버튼을 누르고 아이가 「안녕하세요」라고 말하게 합니다 다 말하면 버튼을 다시 눌러 멈춥니다.
  2. 「마이크가 잘 인식됐어요!」가 나오면 검사 시작
  3. 「목소리가 잘 안 들려요」가 나오면 다시 합니다 마이크를 입 쪽으로 옮기고 조금 크게 말하게 합니다.

버튼을 누르기 전.

이 문구가 보이면 통과입니다.

  • 같은 컴퓨터에서 10분 안에 통과했다면 방금 확인했어요 — 건너뛰기로 넘어갈 수 있습니다.
  • 「마이크를 쓸 수 없어요」가 나오면 화면 안내대로 마이크 권한을 허용하세요.

4연습

연습은 점수에 들어가지 않습니다. 처음 하는 아이는 연습부터 하기, 방법을 이미 아는 아이는 연습 없이 바로 검사 시작을 누릅니다.

아이에게 알려 줄 것

  1. 버튼을 누르면 바로 녹음이 시작돼요
  2. 다 읽으면 버튼을 한 번 더 눌러요
  3. 힘들면 버튼을 눌러 언제든 멈춰도 돼요

연습이 끝나면 「이제 진짜 검사를 시작해요」 화면이 나옵니다.

5검사 진행

아이가 화면의 낱말이나 문장을 소리 내어 다 읽으면 버튼을 눌러 멈추고 다음으로 넘어갑니다. 시간은 재지 않아도 됩니다.

1진행률. 지금 몇 번째 화면인지 보여 줍니다.
2자동 저장됨. 녹음은 끝나는 즉시 저장됩니다. 「저장 중…」일 때는 창을 닫지 마세요.
3녹음 버튼. 누르면 시작, 다시 누르면 끝입니다.
4모르겠어요. 녹음하지 않았을 때 보입니다. 누르면 녹음 없이 넘어갑니다.
5일시정지. 잠시 쉴 때 누릅니다.
6저장하고 나가기. 여기까지 저장하고 나갑니다.
  • 다시 읽히고 싶으면 같은 화면에서 녹음 버튼을 다시 누르면 됩니다.
  • 20초가 지나면 「여기까지예요!」가 뜨고 녹음이 저절로 끝납니다.
  • 아이가 틀려도 멈추지 말고 끝까지 진행해 주세요.
「모르겠어요」로 넘기면 그 화면은 0점입니다

아이가 못 읽겠다고 하면 넘겨도 됩니다. 마이크 문제로 녹음이 비었다면 그 아이는 다시 검사해 주세요.

「저장에 실패했어요」 띠가 뜨면

다시 저장을 누릅니다. 계속 실패하면 그 화면을 다시 녹음하세요.

6멈추거나 나가야 할 때

창이 닫혀도 지금까지 한 것은 남습니다.

일시정지. 잠시 쉴 때 씁니다.

다시 들어왔을 때. 이어서 하기를 누릅니다.

  • 이어서 하려면 같은 컴퓨터, 같은 브라우저로 24시간 안에 들어와야 합니다.
  • 그 사이 같은 컴퓨터에서 다른 아이의 검사를 시작하면 이어서 할 수 없습니다.
  • 되도록 그 자리에서 제출까지 마치세요. 제출하지 않은 검사는 채점되지 않습니다.
새로 시작은 되돌릴 수 없습니다

누르면 그 아이는 처음부터 다시 검사해야 합니다. 이어서 하기와 헷갈리지 마세요.

7쓰기와 체크리스트

쓰기 방식 고르기

쓰기 화면 맨 위에서 아이마다 방식을 고릅니다.

방식하는 일
화면에서 바로 표시화면에 낱말이 나옵니다. 아이가 종이에 쓴 것을 보고 예/아니오(2학년은 0·1·2)를 고릅니다.
스캔본으로 올리기화면에 불러 줄 낱말이 나옵니다. 아이는 기록지에 쓰고, 화면에서는 고르지 않고 넘어갑니다(10장 참고).

화면에서 바로 표시. 맞게 쓴 낱말만 「예」입니다.

스캔본으로 올리기. 아이가 화면을 보지 않게 하고 낱말을 불러 줍니다.

  • 모두 예로 채운 뒤 틀린 것만 바꾸면 빠릅니다.
  • 2학년은 문장마다 맞게 쓴 어절 수(0·1·2)를 고릅니다.
화면에서 표시한 쓰기는 제출한 뒤 고칠 수 없습니다

제출 전 검토 화면에서 한 번 더 확인해 주세요.

검사자 체크리스트

검사하면서 눈에 띈 것이 있으면 표시합니다. 점수에는 들어가지 않습니다.

  • 여러 개를 함께 고를 수 있습니다.
  • 없으면 「특이사항 없음」을 고릅니다.
  • 확실하지 않은 것은 표시하지 않아도 됩니다.

제출하기를 누릅니다.

이 화면이 나오면 끝입니다. 다음 학생 검사하기로 넘어갑니다.

제출하면 고칠 수 없습니다

빠진 녹음은 제출 전에 채워 주세요. 이미 제출했다면 같은 아이를 다시 검사하면 됩니다.

9결과지 받기

채점이 끝난 아이의 결과보고서 PDF를 선생님이 직접 받습니다.

  1. 검사 주소에서 학급 코드를 넣고 확인
  2. 결과지 받기 →를 누릅니다 학급 이름이 있는 띠 안에 있습니다.
  3. 메일로 온 링크를 엽니다 신청할 때 적은 주소로 옵니다. 메일이 없으면 스팸함을 봐 주세요. 링크는 14일 동안 쓸 수 있습니다.
  4. 받을 아이를 고르고 내려받습니다 전체 PDF 다운로드는 받을 수 있는 아이 전부, 선택한 검사 다운로드는 체크한 아이만입니다. 받은 PDF는 공용 컴퓨터에 남기지 마세요.

10쓰기 기록지 인쇄와 스캔본 올리기

쓰기를 스캔본으로 올리기로 하는 반만 보시면 됩니다.

검사 전: 기록지 인쇄

  1. 시작 화면에서 학급 코드를 넣고 쓰기 기록지 인쇄 →
  2. 인쇄하기를 누릅니다 필요한 아이만 뽑으려면 학생 골라서 뽑기를 펼칩니다.
  3. 아이에게 자기 이름이 찍힌 기록지를 줍니다

반 전체 검사 뒤: 스캔본 올리기

  1. 반 전체 기록지를 한 파일(PDF)로 스캔합니다 순서는 섞여도 됩니다. 휴대폰 사진(JPG·PNG)도 됩니다.
  2. 결과지 화면(9장)에서 쓰기 스캔본 올리기로 파일을 고릅니다
  3. 「확인 필요」인 쪽은 이름을 보고 학생을 고릅니다 나머지는 자동으로 연결됩니다.
  4. 올리기를 누릅니다 올리는 동안 창을 닫지 마세요. 종이는 채점이 끝날 때까지 보관하고, 컴퓨터에 남은 스캔 파일은 지워 주세요.

결과지 화면에서 올립니다.

쪽마다 누구 기록지인지 확인합니다.

11이럴 때는

아직 승인되지 않았거나 잘못 친 것입니다. 승인 메일의 코드를 복사해 넣어 보세요.

마이크 확인이 계속 안 돼요

헤드셋이 꽂혔는지, 컴퓨터 소리 설정의 입력 장치가 헤드셋인지 봐 주세요. 그래도 안 되면 다른 헤드셋이나 컴퓨터로 바꾸세요.

아이가 읽기를 거부해요

억지로 시키지 않아도 됩니다. 읽지 않는 화면은 모르겠어요로 넘기세요.

녹음 중에 아이가 딴 얘기를 했어요

그 화면에서 녹음 버튼을 다시 눌러 새로 녹음하면 됩니다.

창이 닫혔어요

같은 컴퓨터로 다시 들어오면 이어서 하기가 뜹니다(6장).

「이어서 할 수 없어요」가 나와요

처음 화면으로를 누르고 그 아이를 처음부터 다시 검사하세요.

쓰기를 잘못 누르고 제출했어요

담당자에게 알려 주세요. 기록을 지우고 다시 검사해야 합니다.

다른 아이의 스캔본을 올렸어요

맞는 기록지를 다시 올리면 바뀝니다. 담당자가 이미 채점을 시작했으면 담당자에게 알려 주세요.

점수는 언제 나와요

담당자가 채점하면 결과지 화면(9장)에서 볼 수 있습니다.

막히면 담당자에게 연락하세요

학교·학년·반과 아이 번호를 함께 알려 주시면 바로 찾을 수 있습니다.
