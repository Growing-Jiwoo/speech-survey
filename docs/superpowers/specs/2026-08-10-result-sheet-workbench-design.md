# 관리자 결과지 → 채점 작업대 재설계 (Design)

**결정**: 사용자가 B안(작업대 재설계) 승인. "봐야 알 것 같음, 되돌아갈 것 고려" → 별도 브랜치
`feat/result-sheet-workbench`에서 구현하고 시각 확인 후 채택/폐기를 결정한다.

## 왜

결과지 화면(`/admin/[id]`)은 "종이 검사지와 같은 순서·구조" 재현을 목표로 설계됐다(2026-08-07
result-sheet-redesign). 이후 공식 출력물이 원본 검사지 PDF 스탬핑으로 옮겨가면서 화면이 검사지를
닮아야 할 이유가 사라졌는데, 그 제약이 남긴 비용(가로 격자·압축된 타이포·플레이어 밀집)은 그대로다.

사용자가 실제 녹음 데이터로 만져 본 뒤 확정한 문제:

1. **글자·밀도** — 섹션 제목 13px, 힌트 10.5px. 위계가 눌려 있고 전체가 빽빽하다.
2. **플레이어 행 밀집** — `2번 문장 · 0:03 · 0:00/0:03 · 1×`가 한 덩어리로 뭉쳐 있다.
3. **배속 `1×`의 × 가 오답 X로 읽힌다** — O/X 채점 화면에서 기호가 충돌한다.

추가 진단(합의됨): `미녹음` 빨간 배지가 한 화면에 6개+ (경보 피로), amber 톤이 경고(임시 기준)와
중립 장식(표 라벨·소계 띠)에 동시에 쓰여 색이 신호 구실을 못 한다.

## 원칙

- **화면은 검사지가 아니라 작업대다.** 과제 순서(낱말 해독 → 문장 → 쓰기 → 체크리스트)만 검사지를
  따르고, 배치는 "듣고 찍는" 동선에 맞춘다. 양식 재현은 PDF가 담당한다.
- **채점 로직 무변경.** `lib/scoring.ts`·저장 API·PDF 스탬핑은 손대지 않는다. 표시 계층
  (`components/admin/**`, `components/AudioPlayer.tsx`)만 바꾼다. 되돌리기 = 브랜치 폐기.
- **타이포 바닥값 12px.** 섹션 제목 16px bold, 본문·문장 15px, 제시 낱말 20px(font-read),
  컨트롤 라벨 13px, 보조 12px. 10.5~11px 전멸.
- **amber는 경고 전용.** 임시 기준 배지·제한시간 초과·제출·미완료에만. 표 라벨·소계 띠의 노란
  바탕은 중립(`well`/`line`)으로.
- **빨간 배지는 원인 자리에 한 번.** `미녹음`은 해당 녹음 슬롯에만. 총괄은 상단 `미완료 N건` 하나.

## 화면 구조 (위 → 아래)

### 1. 머리글 · 총평 밴드 — 구조 유지, 크기만
인적사항 dl 11.5→13px, 담임 줄 10.5→12px. ScoreBand 카드 라벨 11.5→13px. 배치 변경 없음.

### 2. 낱말 해독 — 가로 격자 → 세로 행 리스트 + sticky 플레이어
검사 진행 화면 MarkPage에서 이미 검증된 패턴을 관리자용으로 옮긴다.

- 의미/무의미 **그룹 2개**. 각 그룹 래퍼는 `relative`, 상단 바는 `sticky top-0` — 스크롤하면
  지금 듣는 그룹의 플레이어가 화면 위에 붙어 있고, 다음 그룹에 닿으면 자연스럽게 교대한다.
  **"들으면서 찍기"의 핵심 장치.**
- sticky 바 내용: 그룹 라벨(의미 낱말) · 시도 전환 칩 · 파형 플레이어 · 시간 · 배속. 배경
  white + 아래 경계선, z-10.
- 행: `[낱말 20px font-read] ...... [O 44px] [X 44px]`. 미채점은 버튼 두 개 다 중립.
  데스크톱(lg)은 2열 그리드로 세로 길이를 절반으로.
- 그룹 아래 소계 행(의미 5/7 · 무의미 0/7 · 총점 —/14 · 채점 전/판정) — 중립 배경.

### 3. 문장 읽기유창성 — 문장·플레이어·점수를 한 카드에
문장마다:
- 1행: 번호 + 문장 전문(15px, 어절 단위 줄바꿈).
- 2행: 플레이어(재생 40px · 파형 · 시간 13px · 배속) — 점수 입력과 같은 카드 안.
- 점수: `h-11` 숫자 입력 + `/ 7` 13px. 데스크톱은 오른쪽 열, 모바일은 플레이어 아래.

### 4. 쓰기 과제(검사 중 기록, 읽기 전용) — 격자 → 칩 흐름
읽기 전용 정보에 10행을 쓸 이유가 없다. `낱말 O` `낱말 X` `낱말 —` 칩(색 = mint/rec/mute)을
flex-wrap으로 흘린다. 의미/무의미 그룹 라벨만 유지. G2 문장 쓰기(SentenceWriteRows)는 이미
행 기반 — 타이포만 승격.

### 5. 배속 컨트롤 — `1×` 폐기
AudioPlayer의 배속 Select 라벨을 `배속 1.0` 형식으로(옵션: 0.5 / 0.75 / 1.0 / 1.25 / 1.5).
× 기호는 어디에도 남기지 않는다.

### 6. 체크리스트 · 저장/다운로드 · 범례 — 유지, 12px 바닥값만 적용
