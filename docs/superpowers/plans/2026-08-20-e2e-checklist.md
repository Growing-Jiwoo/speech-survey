## 실행 환경·전제

- dev 서버: `preview_start {name: "dev"}` → http://localhost:3000 (부팅 확인됨 2026-08-20)
- **DB**: `.env.local`의 Supabase에 실제 행이 생긴다. 사용자 승인 아래 진행하며 **Phase 6에서 전부 되돌린다.**
- **관리자 로그인**: 비밀번호를 에이전트가 입력하지 않는다. 사용자가 `/admin/login`에서 1회 직접 입력(쿠키 8시간 → 이후 admin 항목 전체 커버). 로그인 상태가 끊기면 다시 요청한다.

- **메일**: `RESEND_API_KEY` 미설정 → 발송은 반드시 실패한다. **실패 경로 검증이 목적**이고 정상 발송은 미검증으로 남긴다.

### 마이크 스텁 (Phase 3 진입 직후 `javascript_tool`로 주입)

`MediaRecorder`와 `getUserMedia`를 대체한다. blob 앞 4바이트를 **EBML(webm) 매직바이트**로 채워 서버의 `sniffAudio` 검증을 통과시킨다 — 이 값이 틀리면 업로드가 400으로 떨어져 흐름 전체가 막힌다.

```js
(() => {
  const AC = window.AudioContext || window.webkitAudioContext
  // 레벨미터가 0이 아니게: 무음이 아닌 오실레이터를 물린 스트림을 만든다
  const mk = () => { const c = new AC(), o = c.createOscillator(), d = c.createMediaStreamDestination()
    o.frequency.value = 220; o.connect(d); o.start(); return d.stream }
  navigator.mediaDevices.getUserMedia = async () => mk()
  const EBML = new Uint8Array([0x1a,0x45,0xdf,0xa3, ...new Array(2048).fill(0x42)])
  class FakeRec {
    constructor() { this.state = 'inactive'; this.mimeType = 'audio/webm;codecs=opus' }
    start() { this.state = 'recording' }
    stop() { this.state = 'inactive'
      this.ondataavailable?.({ data: new Blob([EBML], { type: this.mimeType }) }); this.onstop?.() }
  }
  FakeRec.isTypeSupported = () => true
  window.MediaRecorder = FakeRec
  return 'stub installed'
})()
```

⚠️ **주입은 페이지 로드마다 날아간다.** `/survey` 새로고침·복원 테스트 뒤에는 다시 주입한다.

### 명단 파일 픅스처 생성 (Phase 1 전에 1회)

`lib/xlsx.ts`는 무압축(stored) 엔트리를 그대로 읽으므로 zlib 없이 만들 수 있다. 아래를 `/private/tmp/claude-501/-Users-kimjiwoo-Desktop-speech-survey/*/scratchpad/mk-roster.mjs`로 저장해 실행한다.

  ['5','','남','2019-07-07',''],                          // ❌ 이름 누락 → 다른 세 칸은 원문 보존

  `<row r="${i+1}">${r.map((c,j)=>
    `<c r="${String.fromCharCode(65+j)}${i+1}" t="inlineStr"><is><t>${esc(c)}</t></is></c>`).join('')}</row>`).join('')}</sheetData></worksheet>`
// 최소 zip(stored) — lib/xlsx.ts는 중앙 디렉터리를 읽고 method 0을 그대로 쓴다
const files = [['xl/worksheets/sheet1.xml', Buffer.from(sheet)]]

let out=[],cen=[],off=0

  const n=Buffer.from(name),c=crc32(data)
  const lh=Buffer.alloc(30); lh.writeUInt32LE(0x04034b50,0); lh.writeUInt16LE(20,4)
  lh.writeUInt32LE(c,14); lh.writeUInt32LE(data.length,18); lh.writeUInt32LE(data.length,22)

  ce.writeUInt32LE(c,16); ce.writeUInt32LE(data.length,20); ce.writeUInt32LE(data.length,24)
