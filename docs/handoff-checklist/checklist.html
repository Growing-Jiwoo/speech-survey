1

학년·학기별 검사 문항과 판정 기준표 (1~6학년)

보내 주세요
지금 상태 1·2학년 2학기 문항과 기준표는 받아서 반영했어요(양호·주의·위험). 1·2학년 1학기는 예전 문항과 임시 기준으로 검사해요. 3~6학년은 검사지가 없어서 같은 학기의 1학년 검사지로 검사해요.
필요한 것
  • 1·2학년 1학기 새 문항과 기준표(내년 3월 검사 전까지)
  • 3~6학년 각 학년의 1학기·2학기 문항과 기준표
  • 2학기 확인 두 가지: 1·2학년 읽기유창성 주의 기준이 둘 다 8.04가 맞는지, 길어진 문장도 문장당 20초로 둘지

안내·동의 문구

확인해 주세요
필요한 것

아래 문구를 그대로 써도 되는지 확인해 주세요. 고칠 곳이 있으면 표시해 주세요.

4

연습 문항 종류

확인해 주세요
지금 상태 본 검사 전에 연습할 때 쉬운 실제 낱말을 보여 주고 있어요.
필요한 것

연습 문항이 "쉬운 실제 낱말"이 맞는지, 아니면 "무의미 낱말(가보·나로 같은)"이어야 하는지 확인해 주세요.

무의미 낱말이라면 연습에서 미리 경험하는 것이 본 검사에 영향을 줄 수 있어서 문항을 어떻게 고를지도 함께 알려 주세요.

5

결과보고서의 「지역 / 학교」 표기

확인해 주세요
필요한 것

지역 / 학교 표기 방식이 맞는지 확인해 주세요. (학기 구분 3~8월 1학기 · 9~2월 2학기는 확인해 주셨어요.)

지역 / 학교

예시로 주신 「춘천 교동초등학교」와 같은 모양으로 맞췄어요.

경우표기예
도 지역 학교시·군 이름(「시」「군」 없이) + 학교명춘천 교동초등학교
특별시·광역시·세종 학교도시 이름 + 학교명부산 운산초등학교
학교 이름이 지역 이름으로 시작지역을 겹쳐 쓰지 않음대구성지초등학교
도의 시 이름이 광역시 이름과 같음도 이름을 앞에 붙임경기 광주 ○○초등학교
위 규칙으로도 다른 학교와 표기가 같아짐 (전국 3쌍)도는 도 이름, 광역시는 구 이름을 더 붙임강원 고성 동광초등학교
부산 해운대구 송정초등학교
