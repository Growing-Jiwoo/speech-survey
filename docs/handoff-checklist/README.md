# docs/handoff-checklist/ — 담당자 확인 사항

담당자(임상 쪽)에게 **정해 주시거나 보내 주셔야 할 것**을 한 장으로 묶어 전달하는 문서다. 담당자는 이 PDF만
읽고 무엇을 보내고 무엇을 확인할지 알 수 있어야 한다 — 이 대화·저장소 맥락을 모르는 사람이 읽는다고 가정한다.

| 파일 | 무엇 |
|---|---|
| `선별검사_담당자_확인사항_초안.pdf` | 전달본(A4 5쪽, 2026-10-12판). `checklist.html`을 뽑은 것 — 1·5번을 고친 2026-10-20 내용은 아직 다시 뽑지 않았다 |
| `checklist.html` | PDF 원본. 판면은 `../manuals/src/style.css`를 함께 쓴다 |
| `checklist.md` | 같은 내용의 글 원본(문구 검토·윤문용). **HTML과 내용을 맞춰 둔다** |
| `shots/` | 3번 항목의 그림 — ① 신청 화면 안내·동의(운영 `/apply` 빈 화면, 담당자가 확인하지 않은 문구만 노란색으로 칠함) ② 승인 메일(`lib/mail.ts` `approvedMail`을 설명서 예시 값 대구가창초 1-2·김서연·`HN4R8K`로 그린 것) ③ 시작 화면 개인정보 안내(운영에서 시험 학급 코드로 띄운 뒤 안내 카드만 — 명단은 찍히지 않음) ④ 마이크 확인 화면(설명서 `t-05-mic.png`과 같은 것)과 아래 두 줄 확대본 |

## 넣지 않는 것

배경·경위(누가 언제 무엇을 말했는지)는 넣지 않는다 — 항목마다 **지금 상태**와 **필요한 것**만 쓴다(사용자 확정 2026-10-12).
보존 기한·검사 일정·도메인·요금제·「저장 실패」 표시는 담당자에게 묻지 않기로 해서 뺐다(사용자 확정 2026-10-12).
IRB 심의는 받지 않는다(사용자 확정 2026-10-12) — 그래서 안내·동의 문구는 「그대로 써도 되는지」만 묻는다.
3번 안내·동의 문구는 **개발 쪽에서 정하고 담당자가 확인하지 않은 것만** 묻는다(사용자 확정 2026-10-12). 담당자가 확정한 문구 —
신청 화면의 「약 5분 내로」, 일시정지·「모르겠어요」 안내, 동의 1번 끝 문장, 동의 3번(담당자 확정 2026-09-21) — 는 그림 1에서 칠하지 않는다.
신청 화면 위쪽 흐름 표시(신청 → 담당자 승인 → …)는 문구가 아니라 단계 표시라 칠하지 않았다.
기준표 전 결과보고서 전달 여부는 넣지 않았다 — 아직 쓰는 학교가 없어 1번의 기준표가 먼저 온다는 전제다.
학교 검사를 기준표보다 먼저 시작하게 되면 그때 다시 물을 것(`docs/qa/2026-10-07-full-e2e.md` 「담당자에게 물을 것」 4번).

## 항목이 코드와 맞물리는 곳

담당자 회신이 오면 아래를 고치고, 이 문서의 해당 항목을 지운다.

| 항목 | 코드 |
|---|---|
| 1. 학년·학기별 문항과 판정 기준 | `lib/forms/g*.ts`(`cutoff`·`provisional`·문항 — 새 양식은 새 id로 추가), 3~6학년 폴백(`formFor`). 1·2학년 2학기는 2026-10-20 반영 |
| 2. 쓰기 기록지 양식 | `components/start/WritingSheets.tsx`(임시 양식) |
| 3. 안내·동의 문구 | `lib/consent.ts`(`SURVEY_NOTICE`·`APPLY_CHECKS`·`CONSENT_NOTICE`·`GUARDIAN_CONSENT_LABEL`·`CHILD_NOTICE`), `app/page.tsx` 시작 화면 안내 둘째 줄, `lib/mail.ts`·`lib/format.ts`(승인 안내 3채널) |
| 4. 연습 문항 | `lib/items.ts` 연습용 낱말 |
| 5. 결과보고서 표기 | `lib/pdf/report.ts`(지역 / 학교), `lib/pdf/README.md` — 학기 구분은 2026-10-20 담당자 확정 |

1번의 2학기 확인 두 가지(읽기유창성 주의 8.04 · 문장당 20초)는 `lib/forms/g1s2.ts`·`g2s2.ts` 주석의 대기 표시와 같다. 코드가 바뀌면 이 문서도 고친다.

## 다시 뽑는 법

크롬 헤드리스 인쇄(`Page.printToPDF`, `preferCSSPageSize`, 배경 인쇄)로 뽑는다. 꼬리말은 설명서와 같은 꼴 —
7.5px, 좌우 16mm, 왼쪽 「읽기 선별검사 · 담당자 확인 사항 · 2026년 10월 판」, 오른쪽 쪽번호(`docs/manuals/README.md` 참고).
카드는 쪽 중간에서 끊기지 않게 두었다(`break-inside:avoid`). 그림이 많은 3번만 세 쪽에 걸치고(그림 2는 새 쪽에서 시작), 이어지는 쪽에서도
테두리가 닫힌다(`box-decoration-break:clone`). 내용을 늘린 뒤에는 쪽마다 제목만 남고 내용이 넘어가지 않았는지 확인할 것. 그림은 쪽 수를 줄이려고 작게 줄이지 않는다 —
담당자가 그림 속 문구를 읽어야 한다(본문 글자가 7pt 아래로 내려가면 다시 배치).
