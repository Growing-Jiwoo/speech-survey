# 교사 결과지 배포 전 E2E 체크리스트 (2026-09-22)

`feat/teacher-results`(PR #69)가 바꾼 것 전부와, **그것이 건드린 기존 기능**을 배포 전에 손으로
확인하는 목록이다. 케이스마다 번호가 있고, 보고는 이 번호로 한다.

이 문서는 스냅샷이 아니라 **현행 문서**다 — 해당 기능이 바뀌면 케이스도 함께 고친다.

## 이번 변경이 건드린 것 (영향 범위)

| 바뀐 것 | 기존에 영향이 가는 곳 |
|---|---|
| `app/page.tsx` 배너·결과지 요청 | **모든 검사의 시작 화면** — 자동 코드 조회·명단/직접 전환·동의 체크 해제 |
| `components/survey/MicCheck.tsx` | **모든 검사의 첫 화면** — 무음 차단이 이 화면의 존재 이유다 |
| `components/admin/sheet/PageAudio.tsx` | 관리자 채점 화면의 녹음 재생(기본 차수) |
| `components/admin/CodeIssuer.tsx`·`lib/schema.ts` | 학급 코드 발급 폼(이메일 필수화) |
| `lib/format.ts`·`lib/mail.ts` | **승인 안내 3채널**(HTML·평문·관리자 복사) |
| `lib/survey-state.ts` | localStorage 키 추가 — 공용 PC에 아동 정보가 남으면 안 된다 |
| `lib/db.ts`·`lib/results.ts` | 추가만 — 기존 채점 사슬(`lib/scoring.ts`)은 변경 없음 |
| `app/apply/page.tsx` | 교사 신청 폼 |
| `app/api/admin/codes/[id]/route.ts` | 기존 DELETE와 같은 파일 |
| `docs/manuals/` | 채점자·검사 진행자가 읽는 인쇄물 |

## 준비

- 개발 서버 `http://localhost:3000`, 관리자 로그인 완료
- 확인에 쓸 학급(실데이터 상태에 따라 다를 수 있으므로 시작 전에 확인할 것)
  - 명단 있는 학급 1개(드롭다운 확인용)
  - 명단 없는 학급 1개(직접 입력 모드 확인용)
  - **재검사가 있는 학급** 1개(차수·기본 재생 확인용)
  - **미승인(pending)** 학급 1개(404 동일성 확인용)
- 토큰은 발송 없이 만들 수 있다(코드 → `classCodeId.exp.HMAC`, `lib/auth.ts`). 메일 발송은 실제로
  나가므로 **1통 이상 보내지 않는다.**

## 실행 기록 — 2026-09-22 (배포 전)

전 항목 실행. **결함 1건을 찾아 고쳤다.**

- **E6 재녹음 구간(수정 완료)** — 「목소리가 잘 안 들려요」 뒤 안내대로 녹음 버튼을 다시 누르면
  `start()`가 `micOk`를 `'none'`으로 되돌려 건너뛰기 링크가 되살아났다. 그 20초 동안 누르면 무음인
  채로 검사가 시작된다. 조건을 `tried`(이 화면에서 한 번이라도 녹음을 눌렀는가)로 바꿔 막았다.

방식별로 나눠 실행했다.

| 절 | 방식 | 결과 |
|---|---|---|
