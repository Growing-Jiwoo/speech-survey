# 전수 점검 체크리스트 · 결과 (2026-10-07~08)

실제 학교 배포 직전, 앱의 **모든 화면·기능·특수 상황**을 한 번씩 밟는 목록이다. 다음 릴리스 때도 이 목록을
그대로 다시 돌린다(결과 칸만 비우고).

## 환경과 원칙

- **운영**(`speech-survey.vercel.app`, main `bc30e0e`)에서 실제로 누른다. 시험 데이터는 학급 **TEST24**(대구가창초 1-2)의
  번호 **90~99**와, 이번에 새로 만든 시험 학급(**VUQCKX** 대구가창초 2-9 · **HAU7XB** 교동초 2-7)만 쓴다. 운영에 실제
  사용자는 아직 없다(사용자 확인 2026-10-07).
- **메일이 나가는 흐름**(신청 알림·승인 안내·결과지 링크)은 **로컬 서버**(같은 코드, 같은 운영 DB)에서 메일 키를 무효값으로
  바꿔 돌린다 — 실제 메일은 한 통도 보내지 않았다. 교사 결과지는 로컬 서버 + 로컬에서 서명한 토큰으로 연다
  (운영과 서명 키가 달라 운영에서는 401 — 정상).
- CSP처럼 운영 빌드에서만 달라지는 것은 로컬 `next build && next start`(운영과 같은 nonce·strict-dynamic)로 본다.
- 마이크는 **합성 신호**(브라우저에서 `getUserMedia`를 발진기로 대체), 인쇄는 `window.print`를 가로채 **인쇄 직전까지**.
- **영구 삭제(세션·학급 코드·스캔본 연결 해제)는 확인 창까지만** 누른다 — 실제 삭제는 사용자가 한다(끝의 「지울 시험 데이터」).
- 결과 표기: ✅ 통과 · ❌ 결함(→ 고친 PR) · ⚠️ 동작은 하나 불편(→ 고친 PR 또는 「UX 제안」) · ⏭ 이번에 못 봄(사유) ·
  🔒 코드·단위 테스트로만 확인

## UX 제안 — 결정이 필요한 것(우선순위순)

1. **Vercel 함수 리전을 서울(icn1)로.** 응답 헤더 `x-vercel-id: icn1::iad1` — 함수가 미국 동부에서 돈다. DB는 서울로 보인다(IPv6
   대역 `2406:da12`, 한국에서 질의 왕복 약 90ms). 같은 요청이 운영 1.6~2.2초, 한국의 로컬 서버 0.18초. 녹음 한 번 저장 4.3초,
   채점 저장·정보 수정 반영 수 초. 대시보드 Settings → Functions → Region 또는 `vercel.json`의 `regions`. 무료 플랜도 한 리전은 고를 수 있다.
2. 교사 결과지를 휴대폰(메일 링크)으로 열면 **판정 열이 가로 스크롤 뒤**에 있다 — 판정을 이름 옆으로 옮기거나 좁은 폭은 카드형으로.
3. 교사 결과지 표에 **과제별 Fail 표시가 없다** — 관리자 화면처럼 기준 미달 점수를 색으로.
4. 관리자 목록: 1024px에서 「상태」 열이 가려짐 · [← 목록]으로 돌아오면 스크롤이 맨 위.
5. 직접 발급한 코드는 메일이 나가지 않는데 [코드 복사]는 코드만 복사한다 — 주소·안내가 든 「안내 문구 복사」.
6. 대기 신청 [삭제] 확인 문구가 승인된 코드용이다 — 「신청 거절」 문구와 「선생님께는 따로 알려 주세요(메일이 나가지 않아요)」.
7. 시작 화면: 성별·생년월일을 안 고르면 [확인]만 꺼지고 이유가 없다.
8. 신청 화면 이메일 확인: 안내는 뜨지만 버튼은 켜져 있고, 대소문자까지 다르게 본다.
9. 문구 체계: 서버 오류 문구는 합니다체(「…못했습니다」「…세션입니다」), 화면은 해요체.
10. 이전 감사에서 나온 낮은 우선순위 항목 — 참여자: 용어 혼용(아동/학생·단계·「1-2」/「1학년 2반」), 연습을 하면 문항 번호가 어긋남,
    머리에 아이 번호 없음, 연습 「잘했어요!」, 제출 확인 문구, iPad 판별, 접근성 / 관리자: 플레이어가 초 단위만, 목록에 채점 상태 없음,
    화면에 최종 결과 없음, 검사지 판 미저장, 일부만 X인 점수 띠, 바뀐 값 없는 수정에도 배지, 같은 이름 학교 합산, 배속 초기화,
    선택 상자에서 Space가 재생을 토글, PDF 파일명에 재검사 차수 없음, PDF 관문이 제출 여부를 보지 않음 / 교사: 재검사 요약·정렬
    불일치, xlsx 숨긴 행 처리, 대비 / 보안: 운영 `APP_URL` 설정 확인, `x-real-ip` 신뢰, 목록 5,000행 상한.
