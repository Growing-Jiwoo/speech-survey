# app/api/admin/sessions/ — 관리자 세션 조회 · 채점 · 파기 · 인쇄

관리자 화면이 쓰는 네 라우트. 검사가 끝난 뒤의 모든 동작(목록 훑기 → 결과지 열기 → 채점 저장 →
검사지 PDF 인쇄 → 파기)이 여기를 지난다. 인증 코드는 없다 — `middleware.ts`가 `/api/admin/*`
전체를 보호한다.

| 파일 | 역할 |
|---|---|
| `route.ts` | `GET` 목록. 세션 + 녹음·쓰기·문장 점수를 조인해 한 번에 내려준다 |
| `[id]/route.ts` | `GET` 결과지 데이터 / `DELETE` 세션 영구 삭제(PII 파기) |
| `[id]/scores/route.ts` | `PUT` 관리자 채점 저장(낱말 O/X · 문장 읽기유창성 어절 수) |
| `[id]/sheet.pdf/route.ts` | `GET` 공식 검사지 PDF — 원본 검사지에 점수만 얹어 내려준다 |

## 설계 의도 · 제약

- **목록에 상한이 있다.** `listSessions`가 `MAX_LIST_ROWS`로 자르고, 상한에 닿으면 경고를
  남긴다(`lib/db.ts`). 화면은 행 가상화로 그 정도를 견디게 만들어 두었지만, 경고가 뜨기
  시작하면 서버 페이지네이션을 도입해야 한다는 신호다.
- **녹음은 서명 URL로만 나간다.** `[id]` GET이 `audio_path`를 서명 URL(1시간)로 바꿔 내려주고
  **스토리지 내부 경로는 응답에 담지 않는다.** service role 키가 클라이언트로 갈 일이 없어야
  하고, 경로가 노출되면 버킷 구조가 함께 드러난다.
- **404와 500을 구분한다.** 삭제된 세션을 장애와 같은 500으로 뭉뚱그리면 운영자가 "재시도"와
  "장애 대응"을 가릴 수 없다. `sessionDetail`이 `session: null`을 돌려주도록 만들어 둔 것이
  이 구분을 위해서다(`.single()`이 아니라 `.maybeSingle()`).
- **채점 저장은 자기 소유 범위를 명시해 넘긴다.** `sentence_scores`에는 관리자 채점(`rs..`)과
  검사 중 수집된 문장 쓰기(`sw..`)가 섞여 있다. `scores` 라우트는 `sentenceCodes`(= `rs..`)를
  `saveScores`에 함께 넘겨 "이번에 안 보낸 행 삭제"의 범위를 제한한다 — 이 인자를 빼면 채점을
  저장할 때마다 아동의 문장 쓰기 점수가 지워진다.
- **무엇이 유효한 문항 코드인지는 세션의 학년이 정한다.** `scores`·`sheet.pdf` 모두 `sessionState`로
  학년을 먼저 읽고 `formForGrade(학년)`의 문항으로 검증·렌더한다. 클라이언트가 보낸 코드를
  그대로 믿으면 다른 학년의 문항이 섞여 저장된다.
- **삭제는 스토리지 → DB 순서다.** `deleteSession`이 녹음 객체를 지운 뒤 세션 행을 지우고,
  나머지 행은 FK CASCADE로 따라 사라진다(행만 지우면 스토리지에 고아 파일이 남는다).
  파기 사실은 `console.info`로 최소 기록만 남긴다 — 관리자 계정이 단일 비밀번호라 행위자
  특정은 애초에 불가능하다.

## 검사지 PDF에만 있는 규칙

- **미녹음 페이지는 오반응(X·0점)으로 채워 인쇄한다.** 다만 **제출된 세션에만** 적용한다 —
  진행 중인 검사의 빈 녹음은 "안 읽었다"가 아니라 "아직 안 했다"다. 화면 결과지와 같은
  `withUnrecordedDefaults`(`lib/scoring.ts`)를 거치므로 화면과 인쇄물이 어긋나지 않는다.
- **파일명은 아동 번호를 두 자리로 앞세운다**(`03_이름_날짜.pdf`, 사용자 확정 2026-08-15).
  한 학급 30명을 한꺼번에 받으면 동명이인 파일이 덮어써지고, 이름 정렬이 출석 번호 순서와
  어긋나 인쇄물을 손으로 다시 줄 세워야 했다. 0을 채워야 문자열 정렬이 번호 순서와 같아진다.
- 한글 파일명은 RFC 5987(`filename*=UTF-8''…`)로 넘긴다 — 없으면 브라우저가 이름을 깨뜨린다.
- 검사일은 KST 기준(`kstDateKey`)이다. UTC로 자르면 아침 검사가 하루 전으로 찍힌다.
- 아동 개인정보가 담긴 문서라 `cache-control: no-store`.

## PII

응답 전체가 아동 실명·생년월일·학교·반·번호와 담임 연락처, 그리고 녹음 재생 URL이다.
`sheet.pdf`는 파일명에까지 아동 이름이 들어가므로 middleware 인증 뒤에서만 접근돼야 한다.

테스트: `tests/admin-routes.test.ts`, `tests/scores-route.test.ts`, `tests/stamp-sheet.test.ts`.
