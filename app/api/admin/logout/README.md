# app/api/admin/logout/ — 관리자 로그아웃

`route.ts` 한 파일. 관리자 쿠키를 `maxAge: 0`으로 덮어써 즉시 만료시킨다. 공용 PC에서 자리를
떠날 때 쓰는 경로다.

**`middleware.ts`가 이 경로를 인증 예외로 통과시킨다.** 이유는 하나다 — 쿠키가 이미 만료됐거나
망가진 상태에서도 로그아웃은 성공해야 하는데, 인증을 걸면 그 상황에서 401이 떨어져 브라우저에
쓸모없는 쿠키가 남는다. 예외를 없애지 말 것.

## 왜 이것만으로 로그아웃이 되나

관리자 토큰은 HMAC 서명 방식이라 **서버측 세션 저장소가 없다.** 지울 상태가 없으니 쿠키 제거가
곧 로그아웃이다. 뒤집으면, 이미 발급된 토큰을 서버가 개별로 무효화할 방법도 없다 —
전체 즉시 무효화가 필요하면 `SESSION_SECRET`을 회전하는 수밖에 없다(참여자 세션 토큰도 함께
죽으므로 검사 시간대를 피할 것. 루트 README 배포 절 참고).

## 함께 봐야 할 곳

- 쿠키 이름·TTL의 단일 소스는 `lib/auth.ts`(`ADMIN_COOKIE`).
- **화면 쪽 뒷정리는 이 라우트가 하지 않는다.** 관리자 목록·결과지·학급 코드는 react-query
  캐시에 PII가 남으므로, `components/admin/AdminDashboard.tsx`의 로그아웃이 `queryClient.clear()`로
  캐시를 비운다. 로그아웃 경로를 새로 만들면 그 정리도 같이 해야 한다.
