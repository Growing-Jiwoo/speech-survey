# app/done/ — 검사 종료 화면

`page.tsx` 한 파일. 제출이 끝난 뒤 도착하는 마지막 화면이며, 여기서 다음 학생의 검사가 시작된다
(`/`로 돌아가는 링크 하나).

## 이 화면이 실제로 하는 일

**진행 상태(localStorage) 파기.** 마운트 즉시 `clearState()`를 부른다. 제출에 성공한 `/review`가
이미 한 번 지우지만, 공용 기기에 세션 id·토큰·아동 이름·번호가 남는 경로를 한 겹 더 막는다
(뒤로가기·직접 진입 등). 이 `useEffect`를 지우지 말 것 — 화면이 하는 유일한 기능이다.

**학급 코드는 지우지 않는다.** 코드만 별도 키(`saveClassCode`)로 남아 있어, [다음 학생 검사하기]로
`/`에 돌아가면 코드는 채워져 있고 아동 정보 칸만 비어 있다. 한 학급을 연달아 검사할 때 코드를
매번 다시 치지 않기 위한 의도다 — 아동 정보(이름·번호·성별·생년월일)는 어느 키로도 남기지 않는다.

## 설계 의도

- **결과·점수를 보여주지 않는다.** 참여자는 자기 녹음을 다시 듣지 않고 점수도 보지 않는다.
  채점은 관리자 결과지에서만 이뤄진다 — 여기에 점수·판정·칭찬 연출을 넣지 말 것
  (평가 신호 비노출은 `components/survey/`의 설계 원칙과 같은 규칙이다).
- 이 화면은 서버와 통신하지 않는다. 제출은 `/review`에서 이미 끝났다.
