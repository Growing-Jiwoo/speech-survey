# lib/forms/ — 학년·학기별 검사지 정의

검사지가 학년과 학기마다 다르므로, 문항·배점·제한 시간·판정 기준·결과보고서 서식을 **양식 데이터**로 두고
검사 진행·채점·결과지·PDF 출력이 전부 이 정의에서 파생되게 했다. **세션을 만들 때** 학년과 검사일의 학기로
`formFor(학년, 학기)`가 양식을 골라 세션 행에 적고(`sessions.form_id`, migration 008), 그 뒤로는 `formOfSession(세션)`이
그 양식을 돌려준다. `form_id`가 없는 세션(migration 008 이전)은 옛 규칙 `formForGrade(학년)`으로 읽는다.

🔒 **`g*.ts`의 낱말·문장은 가짜 문항이다.** 실제 문항은 암호문 `sealed.ts`에만 있고, 키 `FORMS_KEY`가 있으면
`index.ts`가 모듈을 읽을 때 풀어 문항 네 칸(`RealContent`)을 갈아 끼운다(`seal.ts` — AES-256-GCM). 가짜 문항은 실제와
**모양이 같아야 한다**(개수·어절 수) — 배점이 어절 수에서 나와 키 없는 테스트도 실제와 같은 점수 구조로 돌고, 개수가 다르면
`index.ts`가 던진다. Vercel에서 키가 없으면 던진다(가짜 낱말로 검사하지 않게). 고치는 법은 README 「문항 구성」 🔒 표.

⚠️ **한 번 쓴 양식은 고치지 말고 새 id로 추가한다.** 점수는 양식의 자리 번호 코드(`rw01`…)로 쌓이므로, 양식의
낱말을 바꾸면 그 id로 검사한 아이의 녹음이 다른 낱말 옆에 그려지고 다른 기준으로 판정된다. id도 바꾸지 말 것.

⚠️ **검사지(저장소 밖 `private/forms/`)가 절대 기준이다**(1·2학년 2학기는 PDF 없이 담당자 docx `1학년, 2학년 2학기 예비 문항.docx`
(2026-10-19)가 원본). 이 폴더의 문항은 원본을 옮겨 적은 사본일
뿐이며, 코드와 검사지가 다르면 **언제나 검사지가 옳다.** 아동은 검사지의 낱말이 아니라
여기 배열의 낱말을 읽게 되므로, 여기가 틀리면 검사 자체가 다른 검사가 된다(실제로 `rw14`가
'사도'/'사디'로 틀려 있었다(예시 낱말은 가짜 문항) — 2026-08-10 교정). 무의미 낱말은 뜻이 없어 오타가 눈에 띄지 않는다.

| 파일 | 역할 |
|---|---|
| `index.ts` | `SurveyForm` 타입 · `Cutoff`(판정 기준 「이하」) · `FORMS` 레지스트리 · `formFor(학년, 학기)` · `formOfSession(세션)` · `formForGrade(학년)`(옛 세션 전용) · `WritingTask` 판별 유니온 · `ReportStyle`(결과보고서에서 학년마다 다른 서식) |
| `g1s2.ts` / `g2s2.ts` | KODYS-G1-S2 · KODYS-G2-S2 — 1·2학년 **2학기**(담당자 docx 2026-10-19). 판정 기준은 담당자 기준표, 결과보고서 서식은 같은 학년 1학기 양식 것 |
| `g1.ts` / `g2.ts` | KODYS-G1(초1) · KODYS-G2(초2) **1학기** 양식 데이터 — 낱말·문장·쓰기 과제·제한 시간·임시 판정 기준·결과보고서 서식(`report`) |

## 왜 이렇게 나뉘어 있나

- **결과보고서 서식(`report`)은 담당자 docx의 실측값이다.** G1(남색)·G2(초록)가 색만 다른 게 아니라
  체크리스트 머리글·안내문 마침표·줄 간격·빈 줄 수도 다르다 — 담당자 파일이 실제로 그렇다.
  정답본과 1:1이 목표이므로 두 양식을 "맞추지" 말 것(사용자 확정 2026-09-28). 공통 서식은
  `lib/pdf/report.ts`가 갖는다.
- **쓰기 과제는 판별 유니온(`WritingTask`)이다.** G1은 낱말 쓰기(문항 결과가 O/X), G2는 문장
  쓰기(0~어절 수의 정수)로 **과제의 종류 자체가 다르다.** boolean 하나로 뭉개면 세 번째 종류가
  생겼을 때 처리하지 않은 화면·저장·인쇄가 조용히 생긴다 — 유니온이면 전부 컴파일 오류로 드러난다.
- **배점 숫자를 여기 적지 않는다.** 만점은 문장·낱말의 **어절 수**에서 유도한다
  (`lib/scoring.ts`의 `itemMaxWords`) — 검사지의 숫자를 옮겨 적으면 문항을 고칠 때 두 곳이 어긋난다.

## 미확정 사항 (건드리기 전에 확인할 것)

- **1학기 양식(`g1.ts`·`g2.ts`)의 기준은 임시값이다**(`provisional: true` — 관리자·교사 화면에 「임시 기준 · 확정 전」).
  숫자는 만점의 약 65%로 잡은 개발 판단(사용자 확정 2026-08-11)을 3단계로 옮긴 것이라 주의까지만 난다(위험 값 -1).
  1학기 문항도 바뀔 예정이고(담당자 2026-10-20 「1학기 문항도 바껴야하는데, 지금 급한대로 2학기 먼저 준 거야」),
  기준표도 그때 받는다 — 받으면 **새 양식으로 추가**한다(위 ⚠️).
- **`sentenceReading`만 단위가 10초당 어절이다**(정확 어절 ÷ 읽은 시간 × 10, 담당자 확정 2026-09-29 · × 10은 2026-10-20).
- **2학기 기준 가운데 재확인 대기가 둘 있다**(2026-10-20): 1·2학년 읽기유창성 주의 값이 둘 다 8.04인 것, 길어진 2학기 문장에도
  문장당 20초를 그대로 둘지. 바뀌면 `g*s2.ts`의 숫자만 고치면 된다(기준·제한 시간은 문항이 아니라 이미 채점한 세션도 새 값으로
  다시 계산된다 — 확정 회신 전에 학교 결과지를 내보내지 않는 것이 안전하다).
- **`kodys-g2.pdf`는 아직 「가안」이다.** 1학기 문항이 바뀔 때 새 양식과 함께 정리한다.
- **3~6학년은 검사지를 받지 못해 같은 학기의 1학년 양식으로 폴백한다.** 조용한 폴백이 아니다 — 결과지와 인쇄물에
  양식이 찍혀 어떤 양식으로 검사·채점했는지 드러나고, 1학년 기준으로 판정되므로 임시 기준으로 표시한다
  (lib/scoring `criteriaProvisional`).

## 새 양식을 추가하려면

`g*.ts`(문항 + `semester` + `cutoff` + `report` 서식) + 원본(`assets/forms/`, 문항 대조용) 추가 후 `FORMS`에
등록하면 끝이다. 같은 학기 안에서 담당 학년이 겹치지 않는지, 문항 수·배점이 맞는지는 `tests/forms.test.ts`가
검증한다(검사지 낱말은 글자 단위로 대조한다). 결과보고서 출력은 `tests/report.test.ts`.

시행 절차(중단 규칙 등)는 이 폴더가 아니라 `lib/survey-flow.ts`가 정하며, **시행 절차만은
담당자 회신이 인쇄 문구를 이긴다** — [CLAUDE.md](../../CLAUDE.md) 2절 참고.
