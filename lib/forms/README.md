# lib/forms/ — 학년별 검사지 정의

종이 검사지가 학년마다 다르므로, 문항·배점·제한 시간·결과보고서 서식을 **양식 데이터**로 두고
검사 진행·채점·결과지·PDF 출력이 전부 이 정의에서 파생되게 했다. 세션의 학년이
`formForGrade(학년)`으로 양식을 정하고, 양식이 나머지 전부를 정한다.

⚠️ **`assets/forms/`의 검사지 PDF가 절대 기준이다.** 이 폴더의 파일은 원본을 옮겨 적은 사본일
뿐이며, 코드와 검사지가 다르면 **언제나 검사지가 옳다.** 아동은 검사지의 낱말이 아니라
여기 배열의 낱말을 읽게 되므로, 여기가 틀리면 검사 자체가 다른 검사가 된다(실제로 `rw14`가
'봉밥'/'붕밥'으로 틀려 있었다 — 2026-08-10 교정). 무의미 낱말은 뜻이 없어 오타가 눈에 띄지 않는다.

| 파일 | 역할 |
|---|---|
| `index.ts` | `SurveyForm` 타입 · `FORMS` 레지스트리 · `formForGrade(학년)` · `WritingTask` 판별 유니온 · `ReportStyle`(결과보고서에서 학년마다 다른 서식) |
| `g1.ts` / `g2.ts` | KODYS-G1(초1) · KODYS-G2(초2) 양식 데이터 — 낱말·문장·쓰기 과제·제한 시간·임시 Pass 기준·결과보고서 서식(`report`) |

## 왜 이렇게 나뉘어 있나

- **결과보고서 서식(`report`)은 담당자 docx의 실측값이다.** G1(남색)·G2(초록)가 색만 다른 게 아니라
  체크리스트 머리글·안내문 마침표·줄 간격·빈 줄 수도 다르다 — 담당자 파일이 실제로 그렇다.
  정답본과 1:1이 목표이므로 두 양식을 "맞추지" 말 것(사용자 확정 2026-09-28). 공통 서식은
  `lib/pdf/report.ts`가 갖는다.
- **쓰기 과제는 판별 유니온(`WritingTask`)이다.** G1은 낱말 쓰기(문항 결과가 O/X), G2는 문장
  쓰기(0~어절 수의 정수)로 **과제의 종류 자체가 다르다.** boolean 하나로 뭉개면 세 번째 종류가
  생겼을 때 처리하지 않은 화면·저장·인쇄가 조용히 생긴다 — 유니온이면 전부 컴파일 오류로 드러난다.
- **배점 숫자를 여기 적지 않는다.** 만점은 문장·낱말의 **어절 수**에서 유도한다
  (`lib/scoring.ts`의 `itemMaxWords`) — 검사지의 숫자를 옮겨 적으면 문항을 고칠 때 두 곳이 어긋난다.

## 미확정 사항 (건드리기 전에 확인할 것)

- **`passMark`는 임시값이다.** 담당자에게 실제 기준표를 받기 전까지 쓰는 값이며,
  `PROVISIONAL_CRITERIA`가 참인 동안 화면·인쇄물에 "임시 기준 · 확정 전"이 붙는다. 만점이 양식마다
  달라(문장 읽기 G1 36 / G2 35) 양식 데이터로 둔 것이고, 기준표가 오면 숫자만 바꾸면 채점된
  세션도 다시 계산된다.
- **`kodys-g2.pdf`는 아직 「가안」이다.** 확정본을 받으면 원본 PDF 교체 → 문항 배열 →
  `tests/forms.test.ts`의 `SHEET_G2` 갱신이 함께 필요하다. 담당자가 낱말·문장 문항을 학기별로
  2026-10-02(금) 통계 후 확정한다고 했다(낱말이 바뀔 가능성) — 학기별 양식은 아직 없다.
- **3~6학년은 검사지를 받지 못해 G1으로 폴백한다.** 조용한 폴백이 아니다 — 결과지와 인쇄물에
  `form.id`가 찍혀 어떤 양식으로 검사·채점했는지 드러난다.

## 새 학년을 추가하려면

`g*.ts`(문항 + `report` 서식) + 원본 검사지 PDF(`assets/forms/`, 문항 대조용) 추가 후 `FORMS`에
등록하면 끝이다. 담당 학년이 겹치지 않는지, 문항 수·배점이 맞는지는 `tests/forms.test.ts`가
검증한다(검사지 낱말은 글자 단위로 대조한다). 결과보고서 출력은 `tests/report.test.ts`.

시행 절차(중단 규칙 등)는 이 폴더가 아니라 `lib/survey-flow.ts`가 정하며, **시행 절차만은
담당자 회신이 인쇄 문구를 이긴다** — [CLAUDE.md](../../CLAUDE.md) 2절 참고.
