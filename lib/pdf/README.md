# lib/pdf/ — 공식 검사지 PDF 스탬핑

`stamp-sheet.ts` 한 파일. **담당자가 배포한 원본 검사지 PDF를 배경으로 그대로 쓰고 그 위에 점수만
얹는다.** 양식을 다시 그리지 않는 것이 이 모듈의 전부다 — 배경이 원본 그 자체라 출력물은
정의상 공식 양식과 일치하고, 양식이 어긋날 여지가 없다. 이 저장소의 **공식 출력물은 관리자
결과지 화면이 아니라 이 PDF**이며, `GET /api/admin/sessions/[id]/sheet.pdf`가 유일한 호출부다.

좌표·배경 경로·글자 크기는 전부 양식이 들고 있다(`lib/forms/*-layout.ts`) — 이 파일에는
좌표 상수가 없고, 있어서도 안 된다. 학년이 늘어도 여기는 그대로다.

## 지키는 규칙

- **채점하지 않은 칸은 비운다.** 없는 값을 0으로 세어 찍으면 "채점하지 않았다"가 "0점을 받았다"로
  둔갑한다. 종이 검사지에서도 채점하지 않은 칸은 비워 두므로 **빈칸이 곧 올바른 표기**이고,
  그래서 "미채점" 같은 안내 문구도 넣지 않는다(관리자 결과지 화면과 같은 규칙).
- **채점 표시는 인쇄된 글자와 다른 색으로 찍는다.** 같은 색이면 어디까지가 양식이고 어디부터가
  채점 결과인지 구분되지 않는다. 화면 결과지와 같은 의미색을 쓴다(정반응 mint / 오반응 rec-deep).
- **판정에만 색을 쓴다.** 낱말 O/X는 정오 판정이라 색이 뜻을 갖지만, 문장 쓰기의 「0 1 2」
  동그라미는 받은 점수의 표기일 뿐이라 점수와 무관하게 한 색이다.
- **Pass/Fail은 찍지 않는다.** 검사지에 해당 칸이 없고, 임시 기준(`passMark`)에 의한 판정을
  공식 문서에 남기지 않기 위해서다.
- **같은 입력이면 같은 바이트가 나와야 한다.** `PDFDocument.load(…, { updateMetadata: false })` —
  pdf-lib 기본값은 로드 시점에 ModDate를 현재 시각으로 다시 써서, 같은 채점 결과라도 만들 때마다
  파일이 달라진다(출력 재현 불가 + 두 출력을 비교하는 테스트가 초 경계에서 간헐 실패).
  임상 문서라 원본 메타데이터를 그대로 둔다.
- **원본 페이지 크기를 런타임에 검증하고 다르면 던진다.** 좌표는 특정 크기(540×780)를 전제로
  뽑은 값이라, 크기가 다른 개정본이 들어오면 전부 어긋난 인쇄물이 조용히 나가는 대신 실패한다.

## 표기 방식이 양식마다 다르다

- 낱말 쓰기(G1): 낱말 격자에 O/X를 찍고 의미·무의미·총점 소계를 채운다.
- 문장 쓰기(G2): **검사지에 이미 인쇄된 「0 1 2」 중 획득 점수에 동그라미**를 치고 총점만 채운다.

두 방식의 좌표 스키마가 다르므로(`ScoreSlot` vs `ChoiceGridLayout`), 새 쓰기 과제가 생기면
여기와 `lib/forms/layout.ts`를 함께 고쳐야 한다.

## 세부

- 글꼴은 두 굵기를 쓴다. 점수·O/X는 **Bold**(옆에 인쇄된 분모 `/ 7`이 굵어 정체로 찍으면 같은 칸
  안에서 굵기가 어긋난다), 머리글 인적사항은 **Regular**(본문과 섞여야 자연스럽다).
- 학교명이 길면 9pt에서 6pt까지 줄이고, 그래도 넘치면 잘라 낸다 — 실제 학교 목록 6,320곳 중
  250곳이 6pt에서도 넘치는데 가운데 정렬로 흘려보내면 양옆 칸을 덮어 아동의 학년이 읽히지 않는다.
  **이름이 잘리는 편이 낫다**는 판단이다.
- 검사자 구분(교사/전문가)은 수집 자체가 폐기됐다(사용자 확정 2026-08-13). 좌표는 원본 검사지에
  실제로 인쇄된 글자의 실측값이라 `SheetLayout`에 남겨 두었다 — 다시 필요해지면 재추출 없이 쓴다.
- 서버 전용이다. `node:fs`로 `assets/`를 읽으므로 클라이언트 컴포넌트에서 import하지 말 것.
